# Data attribution and transformations

`source.zip` is the unchanged download from the [UCI Seoul Bike Sharing Demand record](https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand), DOI [10.24432/C5F62R](https://doi.org/10.24432/C5F62R).

Citation: *Seoul Bike Sharing Demand* [Dataset]. (2020). UCI Machine Learning Repository.

UCI states the dataset is licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The license permits sharing and adaptation with attribution. The attribution above and this license link must accompany redistribution. Neither the original provider nor UCI endorses this study.

The source bytes are unchanged. Derived outputs use lagged counts, calendar transformations, fitted forecasting models, spline regressions, fixed chronological subsets, and aggregate losses. Weather, functioning-day status and holiday fields are excluded from model inputs. No row is excluded based on outcome magnitude or operational closure status. Dates, rental counts, predictions, and squared errors retain their meanings documented in the protocol. This data license is separate from any surrounding repository software license.
