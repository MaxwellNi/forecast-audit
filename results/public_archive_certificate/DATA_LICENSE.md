# Public source and derived-data terms

Source attribution: **Trindade, A. (2015). ElectricityLoadDiagrams20112014 [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C58C86.**

The [official UCI source page](https://archive.ics.uci.edu/dataset/321/electricityloaddiagrams20112014) licenses the dataset under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The official source zip is available at:

`https://archive.ics.uci.edu/static/public/321/electricityloaddiagrams20112014.zip`

The exact source hash and size used for this study are in `protocol.json`. `reproduce.py --download-source --output NEW_DIRECTORY` fetches that official URL and rejects bytes with a different hash. An existing exact source zip may instead be supplied with `--source`.

The included `forecast_archive.npz` is a derived data artifact and is distributed under **CC BY 4.0** with the source attribution above. Changes comprise selection of the first96 header meters; exclusion of incomplete edge days; arithmetic averaging of each complete nominal96-slot calendar day; chronological feature construction and model fitting; addition of frozen forecasts and a fixed baseline/calendar category; and restriction of the forecast archive to2013–2014. Source zeros are retained. Daily targets are nominal daily mean kW, not physical energy totals adjusted to23/25-hour days.

The numerical tables and sampled-index artifacts are also distributed under **CC BY 4.0** as derived study data. Their statistics and predictions are generated by the accompanying code, not supplied as original UCI measurements. Preserve the original source attribution, this transformation description and the CC BY 4.0 link when sharing the derived data.

The official source describes anonymous meter identifiers; the package adds no identities or private/restricted observations. The source was already public and had previously been used in the project. No endorsement by the data creator or UCI is implied.

Software and helper implementations are covered separately by the included MIT `LICENSE`.
