# Scientific protocol and portable export

The factorial analysis uses already exposed synthetic streams. It is not an independent confirmation, external preregistration, or a fresh domain result. Its protocol is a dated commitment before producing the additional factorial results on those streams.

The historical protocol SHA-256 is `5524550fd1dc1e541d7f499b1081da334e4216f85cd65f93bd847239cf85c6a2`. It was frozen at 2026-09-12 21:27:04.112890 UTC; the run started at 21:27:14.359197 and completed at 21:27:30.440900. The historical executable SHA-256 is `8eaea0b2818f456041bf9c694aab2376ef0b572c79d90c75aaa688305abecc16`.

`provenance/protocol.json` preserves the original scientific settings, dates, failure allocations, complete grid and display commitments. Its input names are translated to this public directory, and it identifies historical executable hashes separately. Consequently its bytes and hash differ from the historical protocol: it is explicitly an exported copy, not a purported original file. The translated start/completion receipts identify both the historical hashes and the exported protocol. Unusable original-layout source files are not distributed; portable code and exact historical code hashes are supplied instead. `provenance/export_trace.json` records this distinction.

An earlier pre-execution protocol is also exported, with its original hash. Before any run-start record or new result existed, the summary serializer was corrected so test-only betting comparators have unavailable lower-bound coverage fields, rather than being counted as failed lower bounds. The scientific grid, confidence rules, random streams and display settings did not change. The final protocol records the earlier protocol hash, and `provenance/preexecution_correction.patch` preserves the exact summary change with reader-facing diff labels.

The final protocol fixes all 100 original settings, all four factorial constructions, all six paired contrasts per setting, and a finite list of display settings. No setting was removed after the additional results were seen. The compact plot uses only previously declared display settings; the full grid remains in the CSV files.

All nine original analysis result files retain their bytes, including the 400,000-row table. The classical-context file is renamed without changing its contents. The 500,000-row original study inputs, its summary and generation protocol, and the 48,000-row comparator inputs/protocol are retained unchanged. Their public paths and original input hashes are recorded in the exported protocol. Historical input code hashes are also retained; they are not falsely used as hashes of the adapted executable code.

Portable changes are filesystem wiring, explicit output-directory arguments, and a one-command reproduction wrapper. The independent verifier locates its primitive helper locally and still imports no producer. The helper uses generic numeric rank comparisons and an independent LP implementation. Inference and paired-interval equations are unchanged. Portable verification writes a new environment-specific receipt instead of overwriting the historical independent receipt.

The publication figure changes the target symbol to vartheta, adds leading zeros to 0.435/0.274/0.070, and adds hats to the two estimated learning allowances. Data, settings, colors, line types, dimensions and font sizes are unchanged. Stable PDF metadata helps later rerender comparisons. The JSON records every plotted value and current source hashes. Earlier figure files remain unchanged in the older evidence collection.

Exact output bytes can depend on library versions. The portable reproduction record reports byte identity separately from numerical agreement, and never labels a different environment's receipt as the same bytes. Requirements list tested Python 3.12 dependency versions. The original analysis used Python 3.9.21 with NumPy 1.26.4 and pandas 2.3.3; the exported historical protocol preserves this fact.
